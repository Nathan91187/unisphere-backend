# UniSphere Backend

UniSphere Backend is a RESTful API built with Spring Boot that powers the UniSphere campus platform. It handles application business logic, data management, authentication, and communication with external services.

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Firebase Authentication
- Cloudinary
- Maven
- Docker

## Features

- User authentication and profile management
- Event creation, discovery, and management
- Event registration management
- Club creation and management
- Club membership and role administration
- Image upload and management

## Architecture

The backend follows a layered architecture, separating controllers, services, repositories, and data transfer objects (DTOs).

It exposes RESTful endpoints consumed by the UniSphere Flutter application.

## Deployment

- **Hosting:** Render
- **Database:** Neon PostgreSQL
- **Containerization:** Docker
